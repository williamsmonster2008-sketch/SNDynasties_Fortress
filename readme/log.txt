❌ 已知严重Bug（待后续修复）
Bug #1: Refugee模式旁系血缘关系缺失

现象: 堂兄弟、堂侄等关系显示为"亲属"或"同族"
根本原因: storeBloodRelationsFromService() 只存储直接关系（父子、兄弟、配偶），未推导和存储旁系关系（堂兄弟、堂侄等）
影响范围: 所有refugee模式生成的人口
临时方案: 显示"亲属"
长期修复: 需要重构血缘关系存储逻辑，添加完整的旁系关系推导算法

Bug #2: 部分角色父母数据缺失

现象: 年轻代际只有父亲没有母亲，或只有母亲没有父亲
可能原因: 数据生成阶段的配偶分配逻辑问题
待验证: 需要检查 _addSpousesForGeneration() 方法

Bug #3: Generation字段不一致

现象: 部分配偶的characterId显示为gen3但generation字段是4
示例: 胡婉华 ID为 spouse_wife_3 但 generation=4
影响: 可能导致辈分判断错误

Bug #4: 伯叔区分未实现

现象: 所有父辈兄弟统一显示"叔父"，未区分"伯父"
原因: 需要 birthOrder 数据判断年龄大小
优先级: 低（可后续优化）
